Tray Audio Bridge：把手机声音无线传到 Windows 电脑

发表于2026-07-29|更新于2026-07-29|项目展示
|总字数:1.1k|阅读时长:3分钟|浏览量:

前言

大家在用电脑玩游戏的时候肯定遇到过这样的场景：等待过场动画、游戏加载、玩网游等复活、等朋友等各种情况，想拿起手机刷个视频，但是环境又不适合外放声音，摘掉播放电脑音频的耳机又很麻烦。所以我让AI制作了 Tray Audio Bridge。它模仿微软商店的 Bluetooth Audio Receiver，可以通过蓝牙直接接收手机音频，也可以配合 Android 发送端，在局域网中将手机允许捕获的媒体声音低延迟传到电脑。

当前版本：Windows v0.4.1 / Android 发送端 v0.3.0

它能做什么

Tray Audio Bridge 提供两种连接方式，可以根据设备和网络环境选择。

蓝牙音频

Windows 端可以作为 A2DP Sink 接收器使用。手机与电脑完成蓝牙配对后，在应用中选择手机并连接，就可以尝试将手机的媒体声音交给电脑的默认扬声器播放。

这一模式不要求手机安装配套应用，适合日常播放音乐、播客和其他媒体内容。

局域网音频

项目同时提供一个 Android 发送端。手机与电脑处于能够互相访问的局域网时，发送端可以将系统允许捕获的媒体或游戏音频传给 Windows 接收端。

局域网模式具备这些设计：

  • 48 kHz、双声道、16-bit PCM 音频
  • 使用较短的数据包降低传输等待
  • 使用 AES-256-GCM 对数据进行验证和加密
  • 连接密钥不会通过网络发送
  • Windows 端显示本机地址、端口与连接状态

它不会尝试绕过 Android 的安全策略。通话、通知、DRM 版权视频，以及主动禁止音频捕获的应用，可能只能得到静音。

为后台使用而设计

这不是一个必须始终放在桌面上的播放器。最小化或关闭主窗口后，Tray Audio Bridge 会继续驻留在 Windows 系统托盘中。

通过托盘菜单可以：

  • 恢复主窗口
  • 启动或停止局域网接收
  • 快速打开 Windows 蓝牙设置
  • 设置开机后台启动
  • 完全退出应用

蓝牙连接出现异常时，应用会尝试清理失败会话并重新连接。针对 Windows 中“显示已经连接，却没有声音”的情况，也提供了强制播放和更深入的音频端点重连处理。

Android APK 使用局域网模式时安装到 Android 10 及以上设备

Windows 端要求 Windows 10 版本 2004（内部版本 19041）或更高版本。如果只使用蓝牙模式，不需要安装 Android APK。

快速使用

使用蓝牙连接

  1. 启动 Tray Audio Bridge。
  2. 在 Windows 设置中完成手机与电脑的蓝牙配对。
  3. 在应用的“蓝牙音频”区域选择手机并点击连接。
  4. 在手机上选择电脑作为蓝牙音频输出。
  5. 播放一段媒体内容，声音将由电脑的默认输出设备播放。

使用局域网连接

  1. 在 Windows 端启用局域网接收。
  2. 记下应用显示的 IPv4 地址、UDP 端口和连接密钥。
  3. 在 Android 发送端填写对应信息。
  4. 点击开始发送，并同意 Android 显示的音频捕获授权。

部分校园网会启用无线客户端隔离。即使手机和电脑连接了同一个校园网账号，两台设备也不一定能够互相访问。遇到这种情况时，可以改用个人热点、家庭路由器或其他允许设备互访的可信网络。

写在最后

Tray Audio Bridge 的目标不是成为一套复杂的投屏平台，而是专注解决一件事：尽可能简单地把手机媒体声音交给 Windows 电脑播放。

目前项目仍会继续完善连接兼容性、状态提示和使用体验。
